# 独立倾转四旋翼无人机 · 项目展示

项目背景、分层控制框架、四旋翼与双旋翼构型示意，以及三段实验记录和一段项目介绍。

展示网址：https://dazimirror.github.io/tiltrotor-demo/

## 内容与交互

- 响应式布局、原生视频控制与全屏观看。
- 视频切换、独立视频链接，支持 `?video=intro#demo` 分享指定视频。
- 构型示意可切换正常四旋翼与对桨停转后的双旋翼。
- 姿态角外环、角速度内环、控制分配与执行器反馈的层级说明。
- 遥控主动注入对桨停转事件；未将其描述为自动故障检测。

框图表达控制层级，构型图为示意，不是具体机械尺寸或固件实现截图。页面不包含性能统计、控制源码、固件、私人报告和联系方式。

## 修改与预览

修改 `index.html` 中的页面文案、`styles.css` 中的样式、`app.js` 中的视频说明和模式交互。视频与封面位于 `media/`。

可在本目录启动任意静态 HTTP 服务器，例如 `python -m http.server 8080`，再访问 `http://localhost:8080/`。

GitHub Pages 使用 `main` 分支的根目录发布，无构建依赖。
